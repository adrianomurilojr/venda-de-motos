# Imagens do projeto

Coloque nesta pasta os arquivos de imagem usados pelo frontend e referencie-os
com caminhos públicos, por exemplo: `/images/minha-moto.jpg`.

As fotos da vitrine de demonstração usam links externos do Unsplash. Os dados
e imagens estão definidos no início de `app/page.js` para facilitar a troca
por dados e arquivos reais quando o backend for integrado.
